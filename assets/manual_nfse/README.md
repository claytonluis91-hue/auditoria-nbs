# Imagens do manual NFS-e

Capturas extraídas, sem edição, do **Guia do Emissor Público Nacional Web da
NFS-e — versão 1.2**, publicado no Portal da Nota Fiscal de Serviço eletrônica.

Fonte oficial:
https://www.gov.br/nfse/pt-br/biblioteca/documentacao-tecnica/documentacao-atual/guia-emissorpubliconacionalweb_snnfse-ern-v12.pdf

As imagens são identificadas no PDF gerado como reproduções do guia oficial.
Ao atualizar o guia, revise as imagens, a constante `VERSAO_GUIA_OFICIAL` em
`manual_nfse.py` e os textos que descrevem os campos.
